# Tecnologías Emergentes

Prácticas y proyecto final de realidad mixta con Unity 2022.3.58f1 y Meta Quest 3.

La documentación con los videos y capturas está en la página del repositorio: abre `index.html`
o actívala en GitHub con **Settings > Pages > Deploy from a branch > main / (root)**.

## Contenido

| Carpeta | Qué hay |
|---|---|
| `index.html` | La página: sección **Proyecto final** y sección **Prácticas**. |
| `Practica_1_RM/` | El proyecto de Unity. Cada práctica es una escena de `Assets/Scene`. |
| `jarvis-rm/` | El código del proyecto final Jarvis: el enlace laptop–visor, la conversión de robots a GLB y los scripts de la app de Unity del visor. |
| `evidencias/` | Video, capturas y jerarquía de cada práctica. |
| `herramientas/` | El generador de la página (`generar_sitio.py`) y el cliente que maneja Unity y graba las evidencias (`puente.py`). |
